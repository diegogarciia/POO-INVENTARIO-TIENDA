# POO: Simulación inventario tienda

Se desea implementar un programa que modela un inventario básico de una tienda.

Permite crear productos, agregarlos a un inventario, calcular el valor total y aplicar descuentos.

En este ejemplo sólo **POO y lógica en consola**.

---

## ⚙️ **Características principales:**

1. **Clases y objetos:**
    - `Producto`: representa cada producto con nombre, precio y cantidad.
    - `Inventario`: gestiona una lista de productos y operaciones sobre ellos.
2. **Métodos OOP:**
    - `agregarProducto()`
    - `eliminarProducto()`
    - `calcularValorTotal()`
    - `aplicarDescuento()`
    - `mostrarProductos()`
3. **Interacción en consola:**
    - Toda la salida se muestra con `console.log()`.
    - Los datos se definen directamente en el código.
